# Дизайн‑токены SkillSwap

## Цвета

### Базовые цвета

- `--color-bg`: основной цвет фона
- `--color-main`: основной цвет фона модулей, инпутов и контрастного текста
- `--color-text-main`: основной цвет текста
- `--color-caption`: цвет текста мелким шрифтом (подписей)
- `--color-accent-main`: основной акцентный цвет
- `--color-accent-dark`: темный акцентный цвет (ссылки, нажатая главная кнопка, выбранный чекбокс, кнопка "все категории" и тд)
- `--color-accent-light`: светлый акцентный цвет (ховер главной кнопки, активное состояние для второстепенных кнопок (Войти, Сообщить об ошибке, назад, отмена))
- `--color-accent-pale`: выцветший акцентный цвет (отключенная главная кнопка, ховеры для выпадашек и второстепенных кнопок и иконок)

### Цвета сопутствующих элементов

- `--color-error`: цвет для рамки и текста у инпута при ошибке
- `--color-alarm`: цвет кружочка нового уведомления у иконки колокольчика

### Цвета тегов и категорий

- `--color-category-business`: Tag_Бизнес и карьера + иконка в списке "Все навыки"
- `--color-category-art`: Tag_Творчество и искусство + иконка в списке "Все навыки"
- `--color-category-lang`: Tag_Иностранные языки + иконка в списке "Все навыки"
- `--color-category-edu`: Tag_Образование и развитие + иконка в списке "Все навыки"
- `--color-category-home`: Tag_Дом и уют + иконка в списке "Все навыки"
- `--color-category-lifestyle`: Tag_Здоровье и лайфстайл + иконка в списке "Все навыки"
- `--color-category-more`: Tag\_+

### Состояния

- основные состояния задействуют базовые цвета, перечисленные выше. Далее перечислены цвета редко повторяющихся состояний

- `--color-text-disabled:`: цвет шрифта деактивированных кнопок ("Войти", "Сообщить об ошибке", "отмена" и "назад")
- `--color-toggle-disabled:`: цвет выключенной иконки переключателя

## Шрифты

- `Roboto Regular`: основное семейство с обычной жирностью для текста и мелких подзаголовков (подключено в `fonts.css`)
- `Roboto Medium`: основное семейство с повышенной жирностью для подзаголовка внутри карточки (навыки) (подключено в `fonts.css`)
- `Jost`: основное семейство для заголовков высокого уровня (заголовки секций, заголовок фильтров и подзаголовки фильтров) (подключено в `fonts.css`)

## Типографика

### Подключенные шрифты

- `--font-text`: Семейство Robotoи бэкап на системные шрифты
- `--font-heading`: Семейство Jost и бэкап на системные шрифты

### Вес шрифтов

- `--font-weight-medium`: повышенная жирность (для заголовков)
- `--font-weight-regular`: обычная жирность (для теста)

### Размеры шрифтов

- `--font-size-text`: размер текста
- `--font-size-heading-section`: размер основного заголовка страницы (и разделов на главной странице)
- `--font-size-heading-filters`: размер заголовка "Фильтры"
- `--font-size-heading-medium`: размрер подзаголовков фильтров и имени в карточке
- `--font-size-heading-card`: размер для подзаголовков в карточке (навыки)
- `--font-size-caption`: размер подписи (мелкий шрифт)

### Межстрочный интервал

- `--font-line-height-text`: стандартный межстрочный интервал
- `--font-line-height-heading-section`: межстрочный интервал основных заголовков страниц
- `--font-line-height-heading-filters`: межстрочный интервал подзаголовка (фильтры)
- `--font-line-height-caption`: межстрочный интервал для подписи (мелкого шрифта)

## Использование

1. Подключите стили в корне приложения:
   ```css
   @import './styles/tokens.css';
   @import './styles/fonts.css';
   @import './styles/typography.css';
   ```
2. Примените базовые стили к компоненту:
   (пример)
   ```css
   body {
     font-family: var(--font-text);
     color: var(--color-text-main);
     background-color: var(--color-bg);
     margin: 0;
     padding: 0;
   }
   ```
