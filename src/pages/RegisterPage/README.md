# README: Работа с собираемыми данными в RegisterPage

Файл: src/pages/RegisterPage/RegisterPage.tsx

## Назначение

Компонент реализует многошаговую форму регистрации пользователя с поэтапным сбором данных. Данные сохраняются и валидируются на каждом шаге, а затем объединяются в финальный объект для регистрации.

## Структура сбора данных

Форма разделена на 3 шага:

### 1. Шаг 1 (аутентификация):

- email;

- пароль.

### 2. Шаг 2 (личная информация и интересы):

- имя;

- дата рождения;

- пол;

- город;

- аватар;

- категория навыка, которому хочет научиться пользователь;

- подкатегория навыка, которому хочет научиться.

### 3. Шаг 3 (навыки для обмена):

- категория навыка, который пользователь может преподавать;

- подкатегория навыка;

- название навыка;

- описание навыка (до 3000 символов);

- фотографии навыка (1–5 фото, до 10 МБ каждое).

## Ключевые механизмы работы с данными

### 1. Кэширование справочных данных

Предварительно загружаются и кэшируются:

- города (cachedCities);

- категории навыков (cachedCategories);

- подкатегории навыков с привязкой к категориям (cachedSubcategories).

Данные загружаются один раз и повторно не запрашиваются.

### 2. Поэтапная валидация

Используется библиотека Yup через react-hook-form. Валидация:

- выполняется при каждом изменении поля (mode: 'onChange');

- на каждом шаге проверяется только релевантный набор полей;

- учитывает зависимости (например, подкатегории зависят от выбранной категории).

### 3. Сбор и хранение данных

- collectedData — накапливает данные со всех пройденных шагов;

- getValues() из react-hook-form — получает текущие значения формы;

- при переходе к следующему шагу текущие данные добавляются в collectedData.

### 4. Восстановление данных при возврате

Функция restoreStepData() восстанавливает данные для конкретного шага из collectedData, если пользователь вернулся назад.

### 5. Обработка файлов

- Аватар: сохраняется как URL (URL.createObjectURL()), тип — string | null.

- Фотографии навыков: массив File[], для превью создаются URL.

- Очистка URL при размонтировании компонента через useEffect и URL.revokeObjectURL().

### 6. Финальная регистрация

При подтверждении:

- валидируется вся форма;

- создаётся полный объект userData с уникальным ID;

- данные сохраняются в localStorage;

- вызывается login(userData);

- пользователь перенаправляется на /profile.

# API и типы

- ## Тип данных формы:

  RegistrationFormData (определён в @/api/types).

- ## Источник данных:

  getMockDbState() (имитация API для разработки).

- ## Аутентификация:
  хук useAuth(), метод login().

### Важные функции

| **Функция**              | **Назначение**                                                                 |
| ------------------------ | ------------------------------------------------------------------------------ |
| loadInitialData()        | Загружает и кэширует города, категории и подкатегории                          |
| validateCurrentStep()    | Валидирует поля текущего шага                                                  |
| handleNext()             | Переходит к следующему шагу, сохраняет данные текущего шага в collectedData    |
| handleBack()             | Возвращается на предыдущий шаг, восстанавливает данные через restoreStepData() |
| collectCurrentStepData() | Получает текущие данные формы через getValues()                                |
| restoreStepData(step)    | Восстанавливает данные для указанного шага из collectedData                    |
| handleConfirm()          | Формирует полный объект userData, сохраняет в localStorage, выполняет вход     |

### Состояния компонента (useState)

- collectedData: накапливаемые данные со всех шагов.

- currentContainer: текущий шаг (1, 2 или 3).

- cityOptions, categoryOptions, subcategoryOptions: опции для выпадающих списков.

- uploadedPhotoUrls, uploadedPhotos: URL и файлы загруженных фото.

- avatar, avatarUrl: файл аватара и его URL для превью.

- authError: сообщение об ошибке авторизации.

- isLoading: индикатор загрузки.

- showPassword: видимость пароля.

- isConfirmationModalOpen: отображение модального окна подтверждения.

- openSelects: отслеживание открытых выпадающих списков.

### Обработка ошибок

- Валидационные ошибки отображаются рядом с полями.

- Общие ошибки (например, загрузка данных) показываются в блоке authError.

- При ошибках регистрации выводится сообщение в модальном окне.

## Использование

1. Перейдите на страницу регистрации (/register).

2. Заполните данные на каждом шаге:
   - Шаг 1: email и пароль.

   - Шаг 2: личная информация и интересы.

   - Шаг 3: навыки для обмена.

3. Используйте кнопки «Назад» и «Далее» для навигации.

4. Проверьте данные в модальном окне подтверждения.

5. Нажмите «Готово» для завершения регистрации.

### Примечания

- Данные сохраняются в localStorage только после успешного подтверждения.

- При перезагрузке страницы прогресс не сохраняется (требуется перезаполнение формы).

- Для продакшена необходимо заменить getMockDbState() на реальный API.

- URL файлов очищаются при размонтировании компонента для предотвращения утечек памяти.
