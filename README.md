# SkillSwap

Платформа обмена навыками в формате **«Я научу / Хочу научиться»** (SPA, группа **48_5**).

Пользователи публикуют навыки двух типов:

- **«Учу»** — чем готовы делиться;
- **«Учусь»** — чему хотят научиться.

Сервис помогает находить пары для обмена, отправлять заявки и отслеживать статус сессий. Данные — из **JSON-моков**; избранное, заявки и настройки — в **localStorage**.

## О проекте

В приложении планируются:

- каталог навыков с поиском и фильтрацией;
- карточка навыка с подробной информацией;
- отправка и обработка заявок на обмен;
- управление текущими и завершёнными сессиями;
- добавление навыков в избранное.

---

## Цель

Сделать удобную платформу взаимного обучения, где можно:

- делиться навыками;
- находить темы для изучения;
- договариваться об обмене;
- фиксировать ход и завершение сессий.

---

## Пользовательский сценарий (User Flow)

1. **Гость открывает главную** — каталог навыков, кнопки «Войти» и «Регистрация».
2. **Поиск и фильтрация** — список обновляется без перезагрузки страницы.
3. **Карточка навыка** — маршрут `/skill/:id`, описание, автор, кнопка «Предложить обмен».
4. **Предложить обмен** — без авторизации редирект на `/login`, после входа возврат к действию.
5. **Автор принимает/отклоняет заявку** — статус «В процессе» или «Отклонена», toast для обеих сторон.
6. **Завершение сессии** — любой участник нажимает «Завершить», статус «Завершена», фиксируется дата.
7. **Создание навыка** — форма на `/create`, валидация, карточка в каталоге без перезагрузки.
8. **Избранное** — тоггл на карточке, `localStorage`, страница `/favorites`.

## Ключевой функционал

- Каталог навыков, поиск и фильтрация.
- Детальная страница навыка.
- Предложение обмена и обработка заявок автором.
- Завершение сессий и дата завершения.
- Создание навыков через форму.
- Избранное.
- Toast-уведомления по важным действиям.

| `/register`  | Регистрация      |
| `/create`    | Создание навыка  |
| `/favorites` | Избранное        |

## Данные и хранение состояния

- **Каталог и карточки:** JSON-моки (например, в `public/` или `db/`).
- **`localStorage`:**
  - избранное;
  - заявки и статусы;
  - настройки пользователя.

---

## Бизнес-правила

- Неавторизованный пользователь при «Предложить обмен» уходит на `/login`.
- После успешного входа выполняется возврат к исходному действию.
- Автор навыка принимает или отклоняет входящую заявку.
- Завершить активную сессию может любой участник.
- Смена статусов отображается сразу, без полной перезагрузки страницы.
