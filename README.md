# SkillSwap

Платформа обмена навыками в формате **"Я научу / Хочу научиться"**.

Пользователи публикуют навыки двух типов:
- **"Учу"** - чем готовы делиться;
- **"Учусь"** - чему хотят научиться.

Сервис помогает находить подходящие пары для обмена, отправлять заявки и отслеживать статус сессий.

---

## О проекте

**SkillSwap** - одностраничное приложение (SPA), в котором реализованы:
- каталог навыков с поиском и фильтрацией;
- карточка навыка с подробной информацией;
- отправка и обработка заявок на обмен;
- управление текущими и завершенными сессиями;
- добавление навыков в избранное.

Источник данных - **JSON-моки**.
Состояния, которые должны сохраняться между сессиями, хранятся в **localStorage**:
- избранное;
- заявки;
- пользовательские настройки.

---

## Цель проекта

Создать удобную платформу для взаимного обучения, где пользователи могут:
- делиться своими навыками;
- находить интересные для изучения темы;
- договариваться об обмене;
- фиксировать процесс и завершение обучающих сессий.

---

## Пользовательский сценарий (User Flow)

1. **Гость открывает главную страницу**
   Видит каталог навыков и кнопки `Войти` / `Регистрация`.

2. **Поиск и фильтрация навыков**
   Каталог обновляется без перезагрузки страницы.

3. **Открытие карточки навыка**
   Переход на маршрут `/skill/:id`, отображаются описание, автор и кнопка `Предложить обмен`.

4. **Отправка заявки на обмен**
   Если пользователь не авторизован, выполняется редирект на `/login` с возвратом после успешного входа.

5. **Обработка заявки автором навыка**
   Статус меняется на `В процессе` или `Отклонена`; обе стороны получают toast-уведомление.

6. **Завершение сессии**
   Любой участник может нажать `Завершить`; статус меняется на `Завершена`, фиксируется дата окончания.

7. **Создание нового навыка**
   На странице `/create` пользователь заполняет форму, проходит валидацию, новая карточка появляется в каталоге без перезагрузки.

8. **Добавление в избранное**
   Кнопка-тоггл на карточке сохраняет состояние в localStorage; список доступен на странице `/favorites`.

## Ключевой функционал

- Просмотр списка навыков (каталог).
- Поиск и фильтрация без полной перезагрузки.
- Детальная страница навыка.
- Предложение обмена навыками.
- Принятие/отклонение заявок автором.
- Завершение сессий и фиксация даты завершения.
- Создание новых навыков через форму.
- Добавление/удаление навыков из избранного.
- Toast-уведомления о важных действиях.

---

## Маршруты приложения

- `/` - главная страница, каталог навыков.
- `/skill/:id` - карточка выбранного навыка.
- `/login` - вход пользователя.
- `/register` - регистрация.
- `/create` - создание нового навыка.
- `/favorites` - избранные навыки.

---

## Структура данных и хранение состояния

- **Каталог и карточки**: данные из JSON-моков.
- **localStorage**:
  - `favorites` - избранные навыки;
  - `requests` - заявки на обмен и их статусы;
  - `settings` - настройки пользователя;

---

## Бизнес-правила

- Неавторизованный пользователь при попытке предложить обмен перенаправляется на `/login`.
- После успешной авторизации пользователь возвращается к исходному действию.
- Автор навыка может только принять или отклонить входящую заявку.
- Завершить активную сессию может любой участник.
- Изменения статусов должны быть сразу видны в интерфейсе (без перезагрузки страницы).
